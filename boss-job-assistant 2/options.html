Chrome 扩展设置

BOSS 软件测试岗位助手

先用本地规则排除硬件、嵌入式、车载和光学岗位，再由扩展直接调用你配置的智谱或 DeepSeek 接口。

个人总结

生成话术时，这段内容会连同当前岗位信息发送给你配置的智谱或 DeepSeek 接口。

简历图片

选择一次 JPG、PNG 或 WebP 图片（最大 8 MB）。图片只保存在当前 Chrome 扩展的本地存储中，不会写进插件文件，也不会发送给智谱或 DeepSeek。

尚未保存简历图片

浏览器不能在以后自动读取一个普通本地路径，所以这里会保存你选择的图片副本。更换图片后需要重新保存。若文字已成功发送、但图片发送结果无法确认，插件会把文字记入防重记录并停止本轮，避免重复给同一招聘者发送文字。

模型接口

可以填写 Base URL，也可以直接粘贴以 /chat/completions 结尾的完整接口地址；插件会自动规范化，避免重复拼接路径。

API Key 会保存在 Chrome 的扩展本地存储中，不会显示在 BOSS 页面或扩展弹窗中；但该存储不是加密密码保险箱。不要在公共或多人共用的 Chrome 配置中保存。

AI 写作要求

这段要求会直接发给模型。默认：先读职位描述，从职责和任职要求里挑1～2个核心点切入，再结合个人总结有针对性地讲自己做过的相关事情和细节，用真人聊天的语气写；你可以继续补充偏好。

强制保护：无论这里如何修改，插件都会禁止自曝短板，也会拦截“把功能、接口、自动化、性能和一串工具全部罗列出来”的菜单式话术。

次数与休息

每份成功发送后随机等待1～3秒（旧配置自动迁移）；以下最短/最长休息是每批成功发送后的额外休息。

当前规则：同岗位第一次沟通后，达到上方最短间隔才允许第二次；第三次从上海时间次日开始允许；同一岗位最多三次。同公司其他岗位在防重时间内不会重复发送。

发送方式

这个开关只控制“确认并发送”单条按钮。自动投放由 BOSS 页面助手中的“开始自动投放”单独启动；启动时会一次性确认本轮上限，此后本轮不会逐条确认。遇到安全验证、频繁操作、发送状态不明确或达到上限会自动停止。
